# Fethet

Dünyanın illerini takımının rengine boya. Saatte bir oy, günde bir seferberlik, $1'a il başkanlığı.

Paint the world's provinces in your team's color: one vote an hour, one rally a day, and province chairs from $1.

- `index.html` – the whole site (GitHub Pages serves it from the repo root)
- `src/` – page source (`shell.html` + `app.js`); `python3 src/build.py` rebuilds `index.html`
- `supabase/` – database functions and edge functions (Supabase backend, Lemon Squeezy webhook)

Province borders: geoBoundaries (CC BY 4.0). Country borders: Natural Earth.
